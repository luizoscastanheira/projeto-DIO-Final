# projeto-DIO-Final

**AVISO IMPORTANTE**
Este é um projeto **puramente acadêmico** criado para exercitar e demonstrar conceitos/técnicas de construção de API REST com java e Spring Boot/ Spring AI !!!

 **O projeto é uma atividade prática baseada no curso da Digital Innovation One.**
 **Link para o repositorio original**: https://github.com/digitalinnovationone/dio-spring-boot-learning-track/tree/main/05-spring-ai

* **Isenção de Responsabilidade:** O autor não oferece suporte, não se resposabiliza por erros, bugs, perda de dados ou por qualquer falha/erro/trapalhada feita por terceiros ao tentar modificar ou utilizar este código em seus estudos ou trabalho.

---

Este projeto demonstra o uso do desenvolvimento guiado por domínio (DDD) em uma aplicação que se conecta a modelos de Inteligência Artificial (LLM). A API é capaz de receber um arquivo de áudio com comandos de voz e utilizá-lo para gerenciar gastos financeiros.
